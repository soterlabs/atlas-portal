# Atlas knowledge-graph data (not included in this drop)

`scripts/build-graph-artifact.ts` derives `public/atlas-graph.json` from six JSON
files in this directory: `meta.json`, `sections.json`, `entities.json`,
`mentions.json`, `edges.json`, `relations.json`. Their contract is
[`schema.md`](schema.md) (schema v2). The files are generated by a separate
knowledge-graph pipeline against a specific Atlas snapshot and must be regenerated
together with the other search artifacts when the Atlas changes; the build fails
loudly when the sections and the corpus disagree.

While this directory holds no data, `npm run search:check-artifacts` reports the
graph as `omitted` and the graph-powered features (Related section, suggestion
chips, definition answers) stay off. Drop the six files here and run
`npm run search:build-graph-artifact -- <corpus-url-or-path>` to enable them.
